# Tech Stack - EYE

## Core Technologies
- **Programming Language:** Python 3.11+ (Managed with `uv`)
- **Web Framework:** FastAPI (with `uvicorn` and `pydantic`)
- **LLM Orchestration:** LangChain (Community, OpenAI, Ollama adapters)
- **Structured Extraction:** Instructor
- **Vector Database:** ChromaDB
- **Communication Protocol:** MCP (Model Context Protocol)
- **Development & Deployment:** Docker, Docker Compose

## Libraries & Tools
- **Logging:** Loguru
- **Parsing/Ingestion:** BeautifulSoup4, Lxml
- **Configuration:** Python-dotenv
- **Testing:** Pytest, Pytest-cov
- **Linting & Type Checking:** Ruff, Mypy
- **Debugging:** Debugpy
